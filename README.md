## О проекте

`git-heatmap` — это консольная утилита и интерактивный TUI-интерфейс для быстрого анализа истории Git-репозитория. Она показывает:

- **Какие файлы менялись чаще всего** — топ "горячих зон" кодовой базы.
- **Когда и кто их менял** — дата последнего изменения и автор.
- **Распределение активности по времени** — график коммитов по дням недели, часам или месяцам.

В отличие от стандартного `git log`, `git-heatmap` даёт *агрегированную* статистику по файлам, позволяя мгновенно понять, где в проекте происходит основная работа.

### Кому это нужно?

- **Разработчикам** — быстро оценить сложность и "возраст" файлов перед рефакторингом.
- **Тимлидам** — понять, какие модули требуют больше внимания.
- **DevOps** — анализировать частоту изменений для планирования CI/CD.
- **Студентам и энтузиастам** — изучать эволюцию открытых проектов.

### Ключевые особенности

- **Высокая производительность** — анализ 100 000 коммитов за секунды (C++ + libgit2).
- **Один бинарный файл** — не требует установки Git или других зависимостей.
- **Два режима работы**:
  - CLI — быстрый вывод таблиц и графиков в консоль.
  - TUI — интерактивный просмотр с навигацией и поиском.
- **Гибкие фильтры** — по дате, автору, ветке, расширениям файлов.
- **Экспорт** — в CSV, JSON и HTML-отчёт.
- **Кроссплатформенность** — работает на Linux, Windows и macOS.
